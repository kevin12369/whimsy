## 已发现并修复的 Bug

### 🐛 [关键] `use_fusion` 任务条件检查失败

**文件**: `src/phaser/scenes/GameScene.ts` — `checkQuestCompletion()`

**问题**: `use_fusion` 分支检查 `this.registry.get('pendingFusedItem') !== undefined`。但这个注册表变量在 `handlePendingFusion()` 中被立即清除。玩家完成融合 → 标志清除 → 去找NPC时条件永远为 `false`，导致森林域第3个任务永远无法提交。

**修复**: 在 `handlePendingFusion()` 中设置独立的 session 级标志 `fusionUsedInSession`，`checkQuestCompletion()` 改为检查此标志，不会被过早清除。

### 🐛 [中] `EffectContext.realmId` 类型不匹配

**文件**: `src/phaser/scenes/GameScene.ts` — 第1218、1321行

**问题**: 使用 `exactOptionalPropertyTypes` 时，`{ realmId: undefined }` 不匹配 `{ realmId?: string }`。`this.expeditionRealm` 类型为 `WorldId | undefined`。

**修复**: 改用条件展开 `...(this.expeditionRealm ? { realmId: this.expeditionRealm } : {})`

### 🐛 [低] `COMPANION_DIALOGUES` 类型过严

**文件**: `src/core/companion.ts`

**问题**: `Record<CompanionId, CompanionLine[]>` 需要全部 11 个 ID，但当前只定义了 3 个伙伴的对话。

**修复**: 改为 `Partial<Record<CompanionId, CompanionLine[]>>`
