## 资源整合策略

### 替换优先级

```
低风险 → 高风险（需要更多适配工作）

UI 元素 ─── 瓦片纹理 ─── 物品图标 ─── 角色精灵 ─── 动画
  (替换最简单)                              (替换最复杂)
```

### 具体替换计划

```
Phase B2: UI 替换
  └─ Kenney Pixel UI → 对话面板、菜单按钮、背包界面

Phase C: 瓦片 + 物品替换
  ├─ Kenney Roguelike Pack → 11 个主题的地面/墙壁/水体瓦片
  ├─ Kenney Roguelike Pack → 30 个物品的图标
  └─ Kenney Roguelike Pack → 玩家角色、NPC角色

Phase D: 特效 + 音效 + 动画
  ├─ Kenney VFX Pack → 拾取/融合/受伤特效
  ├─ Kenney Roguelike Audio → 环境音效
  ├─ Kenney Interface Sounds → UI 交互音效
  └─ Ninja Adventure → 角色行走/冲刺动画
```
