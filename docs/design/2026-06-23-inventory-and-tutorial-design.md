## 方案一: 视觉背包系统 (参考: 宝可梦/勇者斗恶龙)

### 参考对象

| 游戏 | 借鉴点 |
|------|--------|
| **宝可梦 朱/紫** | 分类口袋(道具/重要物品/精灵球/TM)，格子系统，物品详情 |
| **DQ11** | 装备对比，一键整理，分类标签 |
| **塞尔达 旷野之息** | 快速选择轮盘，材料自动分类 |

### 设计方案

```
按 I 键打开背包

┌─────────────────────────────────────────────────────────┐
│  背包                     持有: 3/12                    │
├──────────┬──────────────────────────────────────────────┤
│ 全部      │  ┌────┐ ┌────┐ ┌────┐                      │
│ 消耗品    │  │冰晶 │ │火刃 │ │光球 │                      │
│ 材料      │  │    │ │    │ │    │                      │
│ 融合品    │  └────┘ └────┘ └────┘                      │
│ 重要物品  │  ┌────┐ ┌────┐ ┌────┐                      │
│           │  │ 空  │ │ 空  │ │ 空  │                      │
│           │  │    │ │    │ │    │                      │
│           │  └────┘ └────┘ └────┘                      │
│           │                                              │
│           │  选中: 冰晶                                   │
│           │  行为: splashes on impact                    │
│           │  分类: 消耗品                                 │
│           │                                              │
│           │  [使用] [丢弃] [详情]                         │
├──────────┴──────────────────────────────────────────────┤
│  I关闭 ｜ WASD选择 ｜ E使用 ｜ Q丢弃                       │
└─────────────────────────────────────────────────────────┘
```

### 核心交互

| 操作 | 功能 |
|------|------|
| **I** | 打开/关闭背包 |
| **方向键/WASD** | 在格子间移动选择 |
| **E** | 使用选中的物品 |
| **Q** | 丢弃选中的物品 (需二次确认) |
| **Tab** | 切换分类标签 |

### 分类体系

| 分类 | 包含 | 例子 |
|------|------|------|
| 消耗品 | 一次性使用物品 | rose potion, brine comet |
| 材料 | 融合原料 | ember shard, moss pebble |
| 融合品 | 融合产物 | Prism Sword, Brine Lash |
| 重要物品 | 任务/剧情物品 | 记忆碎片, 回声碎片 |
| 全部 | 以上所有 | — |

### 数据设计

```typescript
interface InventoryItem {
  id: string;
  name: string;
  icon: string;       // sprite key
  description: string;
  category: 'consumable' | 'material' | 'fused' | 'key_item';
  stackable: boolean;
  count: number;
}
```

## 方案二: 引导系统 (New Shuffle → 新手教程)

### 参考对象

| 游戏 | 借鉴点 |
|------|--------|
| **DQ11** | 开场剧情自然引导: 出门→去教堂→打第一个怪，每个步骤有NPC指示 |
| **宝可梦 剑/盾** | 第一个城镇安全区，逐步解锁功能(先教走路→再教抓宠→再教战斗) |
| **Stardew Valley** | 第一天有任务列表引导，但玩家可以自由探索 |

### 设计方案

**"New Shuffle"重命名为"新游戏 (教程)"**

```
主菜单:
  回声档案 (Expedition)     ← 你现在的核心模式
  新游戏 (教程)              ← 原 New Shuffle → 改为完整引导
  设置
```

### 5 步引导流程

```
Step 1 — 移动 (约30秒)
  "按 WASD 或方向键移动角色"
  → 前方有发光路径指引
  → 走到第一个标记点
  → ✅ 解锁: 移动

Step 2 — 交互 (约30秒)
  "靠近物品按 E 拾取"
  → 前方有一个发光物品
  → 按 E 拾取
  → 背包显示物品
  → ✅ 解锁: 拾取

Step 3 — 使用物品 (约30秒)
  "按 I 打开背包，选择物品使用"
  → 前方有一片水(或障碍物)
  → 背包里有 brine comet
  → 使用后冻住水面
  → ✅ 解锁: 物品使用

Step 4 — NPC 对话 (约30秒)
  "靠近 NPC 按 E 对话"
  → 前方有一个发光 NPC
  → 按 E 对话
  → NPC 给融合线索
  → ✅ 解锁: 对话

Step 5 — 融合 (约30秒)
  "找到融合祭坛，把两个物品合在一起"
  → 地图上标记祭坛位置
  → 走近按 E
  → 选择两个物品融合
  → ✅ 解锁: 融合

完成后: "欢迎来到回声世界！前往回声档案开始真正的探险吧"
→ 回到主菜单 / 自动跳转到回声档案
```

### 引导 UI

```
┌─────────────────────────────────────────────────────┐
│  Step 1/5                                           │
│                                                     │
│  ╔═══════════════════════════════════╗              │
│  ║  按 WASD 移动角色                  ║              │
│  ║  走到前方发光的标记点               ║              │
│  ╚═══════════════════════════════════╝              │
│                                                     │
│  ████████░░░░░░░░░░░  进度 50%                       │
└─────────────────────────────────────────────────────┘
```

### 实现要点

| 功能 | 实现方式 |
|------|---------|
| 步骤追踪 | 全局 tutorial 状态机 (tutorialStep: 0-5) |
| 引导提示 | 半透明提示框 + 可关闭 |
| 目标标记 | 地图上生成发光标记点，玩家走到即触发下一步 |
| 进度保存 | localStorage 标记 "tutorial_completed" |

## 方案三: 融合祭坛可见性

### 问题
祭坛在地图某处，没有指示，玩家可能绕整个地图找。

### 解决方案

```
3 层可见性:
  1. 祭坛位置在地图上有一根发光的紫色光柱（贯穿迷雾）
     → 在 fog overlay 之上额外绘制紫色竖线
  
  2. HUD 显示方向和距离
     → "祭坛 ⬆ 12格" 或 "祭坛 ⬅ 5格"
  
  3. 走进祭坛 10 格范围时，祭坛自身脉冲发光
     → 现有的紫色星号动画增强
```

### 祭坛指示器 HUD

```
┌────────────────────────────────────┐
│ L2 Forest     ❤❤❤          ⬆12   │
│ 怪癖: trees lean toward player    │ ← 祭坛方向+距离
│ INV: brine comet, rose potion     │
└────────────────────────────────────┘
```

## 方案四: 背包满了可管理

### 当前问题
满时只显示红色文字，玩家不知道怎么办。

### 解决方案

| 情况 | 方案 |
|------|------|
| 背包满了按 E 捡物品 | → 打开背包界面，提示"背包已满，请腾出空间" |
| 想腾空间 | → 选中物品按 Q 丢弃 (二次确认: "确定丢弃 [物品名]?") |
| 想用物品 | → 选中物品按 E 使用 (如果当前场景可用) |
| 物品太多看不清 | → 分类标签过滤 |
