# Whimsy Shuffle — 全系统回归测试计划

> 目标：在所有已知问题上修复合后，让用户进行一次完整的游戏体验而不遇到故障。
> 方法：按系统逐一检查，修复后再进行后续测试。

## 测试清单

### [A] 引导流程 — 从主菜单到教程完成

- [ ] 打开页面 → BootScene 加载 → 跳转 MenuScene
- [ ] 点击"新游戏(教程)" → GameScene 启动，无报错
- [ ] 教程第1步：WASD 移动，走到发光标记
- [ ] 教程第2步：靠近物品，按 E 拾取
- [ ] 教程第3步：按 Q 使用物品冻水
- [ ] 教程第4步：靠近 NPC，按 E 对话
- [ ] 教程第5步：走到祭坛，按 E 打开
- [ ] 完成教程 → 跳回主菜单，"回声档案"变可用

### [B] 远征模式 — 回声档案 → 碎镜域选择 → 5层探索

- [ ] 回声档案页面加载正常，显示进度/伙伴/能力
- [ ] 点击"开始探险" → DomainSelectScene
- [ ] 选择碎镜域 → GameScene 以远征模式启动
- [ ] 迷雾正常渲染（深色覆盖 + 圆形可见区域遮挡）
- [ ] 每层地图生成正常（大小递增）
- [ ] 每层物品/NPC/祭坛放置正常
- [ ] 到达出口 → 进入下一层（或获得回声返回）
- [ ] 第5层通关 → 回声保存 → 跳回回声档案

### [C] 背包系统 — 打开/使用/丢弃/关闭

- [ ] 按 I 打开背包（无报错）
- [ ] 分类标签切换 (全部/消耗品/材料/融合品/重要物品)
- [ ] 方向键/WASD 选择物品
- [ ] 按 E 使用物品（场景可用时生效）
- [ ] 按 Q 丢弃物品（二次确认）
- [ ] Tab 切换分类
- [ ] I/Esc 关闭背包 → 恢复游戏
- [ ] 背包满时尝试拾取 → 提示

### [D] 对话系统 — 显示/隐藏/层级

- [ ] NPC 对话 → 底部面板正常显示（名称+正文+▼指示器）
- [ ] 对话框在 y=584~638，紧贴手牌区上方（手牌在 y=640），不遮挡地图中间区域
- [ ] 点击关闭对话框
- [ ] 连续触发对话不丢失（队列机制）
- [ ] 伙伴对话气泡显示在伙伴头上

### [E] 伙伴系统 — 跟随/对话/被动能力

- [ ] 伙伴在身后正常跟随（延迟移动）
- [ ] 按 E 触发伙伴对话（事件触发）
- [ ] 苔藓被动：附近物品闪烁高亮（每秒检测6次）
- [ ] 潮汐被动：水域减速 15%（vs 55%）
- [ ] 余烬被动：视野半径 150px（vs 100px）

### [F] 物品系统 — 跨域效果

- [ ] 火系物品在森林烧植被，在海洋蒸水，在沙漠化墙
- [ ] 冰系物品冻结水面（所有域）
- [ ] 光系物品在森林/地牢揭示隐藏通道
- [ ] 切割物品斩断藤蔓/破坏墙壁
- [ ] 恢复物品回血
- [ ] 探测物品揭示隐藏结构

### [G] UI 布局 — 无重叠

- [ ] 对话框与手牌区不重叠
- [ ] 祭坛指南针在右上角正常显示

### [H] 性能 — 长时间运行不卡死
