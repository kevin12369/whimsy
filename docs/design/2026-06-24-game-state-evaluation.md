## 3. 可玩性评估

### 玩家体验路径

```
主菜单 → 教程(5步) → 回声档案 → 选域(3选1) → 
  远征(5层) → 收集碎片/伙伴/故事 → 
  回声档案(查看进度) → 下一个域 → 
  11域全通 → 结局(需实现D2)
```

### 单次游戏时长
- 教程: ~3-5 分钟
- 一个域(5层): ~10-15 分钟
- 全收集(11域): ~2-3 小时
- 完成所有任务: ~3-4 小时

### 重玩性
- 污染系统提供 40% 概率的域变体
- 3种关卡目标随机分配
- 11个域可自由选择顺序
- 伙伴招募顺序影响游戏体验
