# Whimsy Shuffle: Echoes of a Fractured World

> **Game Design Document v2.0 — Complete Redesign**
> 2026-06-23 | Author: GameDesigner

---

## 世界观 — 裂镜纪事

### 世界起源

世界曾是完整的。创世神器 **"棱镜"** 将十一种元素调和为和谐的整体——森林、海洋、地下城、星械、沙漠、冰原、丛林、水晶、霓虹、幽魂、天境，彼此交织，生生不息。

直到某个不可知的日子，棱镜碎了。

**为什么碎？** 这一点玩家将在旅程中逐步发现。每个碎片区域都藏着记忆残影，拼凑出真相。

棱镜的碎片坠入现实，把世界撕裂成十一个独立的"碎镜域"。每个碎镜域都被一种元素主宰，其他元素被排斥在外。时空变得不稳定——世界在这些碎片之间不断"洗牌"。

### 玩家身份

你是 **回声行者 (Echo-walker)**——在最后一次"洗牌"中被唤醒的存在。你拥有两个能力：
1. **回声感知**：能感知到棱镜碎片残留的记忆和情感
2. **域隙行者**：能在碎镜域之间移动（但这需要能量——回声碎片）

你的目标：进入十一个碎镜域，收集棱镜的回声，决定世界的命运。

### 叙事驱动力

这不是一个"打败魔王"的故事。这是一个**探索与理解**的故事：

- **每个碎镜域**都保存着棱镜的一块记忆碎片
- **每个碎镜域**的居民都记得世界破碎前的一小段历史
- **每个碎镜域**的独特物理规则，反映了棱镜被撕裂时的那一瞬间发生了什么

随着玩家收集回声，一幅更大的图景浮现。最终，玩家要回答一个问题：

> **这个世界应该被修复吗？还是让碎片各自为政更好？**

## 有趣在哪里？— 设计宣言

这个游戏不再是你之前看到的"走到出口"。它有三个**核心乐趣**：

### 1. 探索的乐趣 —— "那边有什么？我想去看看"

```
每个碎镜域 = 一个微型的主题世界，每个世界有:
  ├─ 独特的视觉风格（✓ 已有的11个主题）
  ├─ 独特的物理规则（NEW！不再是文字装饰）
  ├─ 独特的谜题机制（NEW！每个域一个核心谜题）
  ├─ 独特的危险模式（NEW！不仅掉血，还会改变玩法）
  └─ 隐藏的叙事碎片（NEW！拼凑世界观剧情）
```

### 2. 操作的乐趣 —— "我做到了！"

```
玩家不再只是走路，现在可以:
  ├─ WASD 移动（基础）
  ├─ 冲刺 Dash（空格键，有冷却）—— 躲避危险、跨越缝隙
  ├─ 回声扫描 Echo Scan（Q键，范围探测）—— 找到隐藏物品
  ├─ 物品使用 Item Use（E键交互菜单）—— 不再只是"冻水"，有更多效果
  └─ 域力共鸣 Realm Resonance（F键，区域专属能力）—— 每个碎镜域给一个特殊能力
```

### 3. 发现的乐趣 —— "原来是这样！"

```
发现的三个层次:
  表层: 找到隐藏物品、解锁近路、发现回声碎片
  中层: 理解这个碎镜域的"规则"，利用规则通过难关
  深层: 收集所有记忆碎片，拼凑出棱镜破碎的真相
```

## 十一个碎镜域

每个碎镜域不只是换颜色——它有**四个独特维度**。
(标 ★ = 推荐先从这几个域开始实现)

### 完整规格

| 碎镜域 | 核心规则 | 危险 | 域力共鸣 | 叙事碎片 |
|--------|---------|------|---------|---------|
| **Forest** ★ | 藤蔓封锁路径，需要火/切割类物品开路 | 荆棘丛(减速+掉血) | **树灵之触**: 操控藤蔓，暂时开门 | "森林记得那个黎明..." |
| **Ocean** ★ | 潮汐周期: 退潮/涨潮，影响通行区域 | 暗流(每秒位移，掉向陷阱) | **潮汐掌控**: 强行改变水位，持续5秒 | "海洋是最先哭泣的..." |
| **Dungeon** ★ | 光明范围: 角色周围有亮圈，圈外受伤害 | 暗影爬行者(向亮圈靠近) | **耀斑爆发**: 瞬间照亮全层3秒 | "地牢守住了最重的秘密..." |
| **Sci-Fi** | 重力区: 地图分高/低/零重力区域 | 能量场(触碰会弹开+掉血) | **重力反转**: 局部重力逆转，跳上高台 | "星械城的建造者知道真相..." |
| **Desert** | 沙暴周期: 能见度降低，沙丘移动 | 流沙(沉入即重置至层入口) | **沙之眼**: 看穿沙暴，标记隐藏路径 | "沙漠埋藏了创世者的名字..." |
| **Tundra** | 体温系统: 寒冷区域持续掉血，需要光源取暖 | 冰裂隙(掉入即受伤) | **融暖光环**: 周围产生热区，持续8秒 | "冰原封锁了门的钥匙..." |
| **Jungle** | 毒素区域: 彩色雾气区持续中毒 | 毒藤(触碰后视野扭曲，方向反转) | **净化之息**: 清除周围毒雾+回复1HP | "丛林蔓延在伤口之上..." |
| **Crystal** | 折射光束: 调整水晶角度，光束打通路径 | 水晶尖刺(地面突出，周期性出现) | **棱镜折射**: 改变光束方向解谜 | "水晶记录了最后的声音..." |
| **Neon** | 信号塔: 需要按照特定顺序激活塔 | 电网(连接的电网区域伤害) | **超载脉冲**: 使周围塔暂时失效 | "霓虹下的交易从未停止..." |
| **Haunted** | 相位穿行: 可穿越特定墙壁(有限次) | 亡灵(追踪玩家，触碰即受伤) | **灵体分离**: 短时间无敌+穿墙 | "鬼域里有一位永远等待的人..." |
| **Sky** | 气流通道: 风推动玩家，需要控制方向 | 虚空空洞(坠落即重置至层入口) | **逆风之翼**: 逆风飞行，抵达高处 | "天空之上，是世界的尽头..." |

### 域力共鸣设计原则

每个域的 F 键能力是**有限次使用**的(每层 2-3 次)，让玩家在"现在用"还是"留着应对后面的危险"之间做选择。

## 玩家能力成长 (跨会话)

### 回声档案 (Echo Archive)

在主菜单和游戏之间新增一个**中间页面**。它展示你的永久进度。

| 解锁项 | 需要回声数 | 效果 |
|--------|-----------|------|
| **冲刺 (Dash)** | 0 (初始拥有) | 空格键短距冲刺，冷却 3 秒 |
| **回声扫描** | 1 | Q 键脉冲探测半径 4 格内的隐藏物品和陷阱 |
| **域力共鸣** | 3 | F 键激活当前碎镜域的特殊能力 |
| **物品起始包** | 5 | 每次进入碎镜域自带 1 个随机物品 |
| **回声护盾** | 7 | 每层第一次受伤减半 |
| **域隙导航** | 9 | 选择碎镜域时能看到"是否有未收集的回声碎片" |
| **完整记忆 (结局前置)** | 11 | 解锁最终抉择章节 |

**为什么这个系统很重要？** 因为它给了玩家"再来一局"的理由。"再打一局就能解锁域力共鸣了"——这比"再看一次不同颜色"有力量得多。

### 实现方式

用 `localStorage` 保存解锁状态。很轻量。

```typescript
interface EchoArchive {
  collectedEchoes: string[];     // 已收集的回声 ID
  unlockedAbilities: string[];   // 已解锁的能力
  totalFragmentsCollected: number; // 累计收集碎片数
  sessionsCompleted: number;     // 完成会话次数
}
```

## 物品系统重设计

现有 30 个物品保留，但每个物品获得**更清晰的功能映射**。

### 物品种类矩阵

| 类别 | 行为 | 例子 | 用途 |
|------|------|------|------|
| **火系 🔥** | 燃烧 | ember shard, ash flake | 烧藤蔓、取暖、照明 |
| **冰系 ❄️** | 冻结 | brine comet, frost splinter | 冻水面、冻结陷阱 |
| **光系 💡** | 照明 | lantern wisp, sun coin | 驱散黑暗、显形隐藏物 |
| **切割 🗡️** | 切割 | cyan blade, vine whip | 切断藤蔓、开路 |
| **治愈 💚** | 恢复 | rose potion, dill drone | 回血、解毒 |
| **探测 🔍** | 感知 | pickled star, amber bead | 显示附近物品/陷阱 |
| **干扰 ⚡** | 控制 | ferment orb, sour drop | 减慢敌人、反转机关 |

### 物品使用改进

不再是"有特定物品才能用"。现在:
- **靠近可互动的物体 → 按 E 显示菜单 → 选择使用哪个物品**
- 如果物品与场景不匹配，会显示"这个物品在这里没用"
- 融合后的物品有更强的效果（如 Glow Pickle = 照明 + 治疗）

## 难度与节奏

### 每个碎镜域的 5 层

```
层1 - 门槛   : 安全区，无危险，只有1-2个物品 → 让玩家熟悉规则
层2 - 探索   : 引入1个陷阱类型，2-3个物品 → 开始有选择
层3 - 挑战   : 2个陷阱类型混合，1个回声碎片 → 风险增加
层4 - 深渊   : 高密度威胁，2个回声碎片 → 真正的考验
层5 - 核心   : 回声守卫(谜题/逃脱)，完成后获得回声 → 高潮
```

### 难度的"可感升级"

| 层 | 玩家应该感觉到 |
|----|--------------|
| 1 | "哦，这是在教我..." |
| 2 | "我懂了，这里我需要用物品" |
| 3 | "有点紧张了，血不多了" |
| 4 | "深呼吸...集中..." |
| 5 | "！！！原来是这样的！！" |

### 实现优先级

分 4 个阶段实施，每个阶段产出"可玩的"版本:

```
Phase 1 — "骨架" (你现在能玩)
  └─ 回声档案页面 + 碎镜域选择器 + 5层系统 + 冲刺

Phase 2 — "血肉" (变得有趣)
  └─ 3 个优先域的核心规则(Forest/Ocean/Dungeon) + 域力共鸣
  
Phase 3 — "世界" (内容量翻倍)
  └─ 剩余 8 个域 + 物品分类系统 + 融合效果增强

Phase 4 — "灵魂" (叙事的价值)
  └─ 叙事碎片 + 33 段记忆文本 + 最终抉择
```
